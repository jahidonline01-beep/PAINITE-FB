# Painite FB PRO

Custom Facebook WebView toolkit (cookies, 2FA, name generator, Account Centre overlay).

## Build
```
./gradlew assembleDebug
```
APK name: **Painite FB PRO** (version 1.3.0)

## Features
- Mobile: system WebView UA (natural)
- Desktop toggle: www.facebook.com + wide layout
- Account Centre overlay (no refresh on tab switch)
- Home / Back / Clear / Cookies
- No auto-refresh, no fingerprint spoof, no FB traffic blocking

## Note
This is not the official Facebook app. Account risk depends on IP and Facebook server policy.
